# 恐龍百科核心專有名詞對照表 (DinoWiki Glossary)

本名詞表作為 DinoWiki 的標準規範字典。在撰寫條目時，請依此表的標準譯名與專有名詞書寫。

---

## 1. 地質年代 (Geological Time)

| 中文名稱 | 英文 / 拉丁名稱 | 縮寫/代號 | 典型年代跨度 (Ma, 百萬年前) | 備註說明 |
| :--- | :--- | :--- | :--- | :--- |
| **中生代** | Mesozoic Era | - | ~252 – 66 Ma | 恐龍興衰的地質時代 |
| **三疊紀** | Triassic Period | T | ~252 – 201 Ma | 晚期出現恐龍祖先 |
| **侏羅紀** | Jurassic Period | J | ~201 – 145 Ma | 巨型蜥腳類與異特龍盛世 |
| **白堊紀** | Cretaceous Period | K | ~145 – 66 Ma | 暴龍、角龍多樣性頂峰 |
| **白堊紀—古近紀界線** | Cretaceous–Paleogene Boundary | K-Pg (舊稱 K-T) | ~66 Ma | 希克蘇魯伯小行星撞擊滅絕事件 |

## 2. 系統分類學階元 (Taxonomy & Clades)

| 中文名稱 | 英文 / 學名 | 骨盆特徵與演化地位 | 代表物種 |
| :--- | :--- | :--- | :--- |
| **主龍類** | Archosauria | 恐龍、翼龍、鱷魚的共同祖先群 | 派克鱷 (*Euparkeria*) |
| **恐龍總目** | Dinosauria | 直立行走的雙孔亞綱陸生爬行動物演化支 | 所有恐龍及鳥類 |
| **蜥臀目** | Saurischia ("Lizard-hipped") | 恥骨通常朝前，下分獸腳類與蜥腳形類 | 暴龍、梁龍 |
| **獸腳亞目** | Theropoda | 雙足肉食（少數植食）恐龍，鳥類由此演化 | 異特龍、伶盜龍、鳥類 |
| **蜥腳下目** | Sauropoda | 四足巨型長頸長尾植食性恐龍 | 迷惑龍、腕龍、阿根廷龍 |
| **鳥臀目** | Ornithischia ("Bird-hipped") | 恥骨轉向後方與坐骨平行，全部為植食性 | 三角龍、劍龍、甲龍 |
| **裝甲類 / 覆盾甲龍類** | Thyreophora | 體表具皮內成骨（骨板、骨刺、骨甲） | 劍龍、包頭龍 |
| **角龍下目** | Ceratopsia | 具喙狀嘴、頭盾、角狀突起 | 原角龍、三角龍 |
| **鴨嘴龍科** | Hadrosauridae | 具扁平鴨嘴、極度發達的齒電池構造 | 埃德蒙頓龍、副櫛龍 |

## 3. 解剖學構造 (Anatomy & Structures)

| 中文名稱 | 英文名稱 | 所屬主要類群 | 功能與常見易混淆點 |
| :--- | :--- | :--- | :--- |
| **尾刺** | Thagomizer | 劍龍亞目 (*Stegosauria*) | **由 4 根尖銳骨刺組成**，作防禦與橫掃攻擊。**嚴禁稱為尾槌**。 |
| **尾槌** | Tail Club | 甲龍科 (*Ankylosauridae*) | 由數塊融合的皮內成骨與骨化肌腱形成的骨質重錘。 |
| **齒電池** | Dental Battery | 鴨嘴龍類、角龍類 | 緊密排列、多層替換的數百至上千顆磨齒，適應粗韌纖維。 |
| **頭盾 / 頸盾** | Neck Frill / Parietosquamosal Frill | 角龍亞目 (*Ceratopsia*) | 頂骨與鱗骨延伸形成的骨質頸盾，用於保護、威嚇、求偶。 |
| **羽莖瘤** | Quill Knobs | 馳龍科等獸腳類恐龍 | 尺骨上供正羽羽軸韌帶附著的突起，是羽毛的骨骼印證。 |
| **第二趾鐮刀爪** | Sickle Claw / Enlarged Ungual | 馳龍科 (*Dromaeosauridae*) | 高度特化、可向上收起的第二趾巨爪，用於鎖定與抓握獵物。 |
| **骨板** | Plates | 劍龍亞目 (*Stegosauria*) | 背部雙排交錯的扁平皮內成骨，具展示、威嚇與體溫調節潛能。 |
| **腸骨 / 坐骨 / 恥骨** | Ilium / Ischium / Pubis | 所有恐龍 | 組成骨盆的三塊核心骨骼，為蜥臀與鳥臀分類判別標準。 |

## 4. 行為學與生態名詞 (Paleoethology & Ecology)

| 中文名稱 | 英文名稱 | 定義與科學意義 |
| :--- | :--- | :--- |
| **親代撫育** | Parental Care | 成體對蛋與幼體的孵化、護巢與餵養行為（如竊蛋龍、慈母龍）。 |
| **內溫性 / 中溫性** | Endothermy / Mesothermy | 體溫維持與新陳代謝水平高於冷血爬行動物，支持活躍生活方式。 |
| **顱骨可動性** | Cranial Kinesis (Pleurokinesis) | 上頜骨骼在咬合時能產生彈性形變與微動，提高植物研磨效率。 |
| **機會主義聚集** | Opportunistic Mobbing | 掠食者在同一目標周圍聚集爭食，缺乏高等社會分工（馳龍科真實習性推論）。 |
| **撞擊冬天** | Impact Winter | 小行星撞擊後大氣懸浮微粒與含硫氣膠遮蔽日光，導致全球光合作用停擺與寒冷。 |
| **非鳥恐龍** | Non-avian Dinosaurs | 在 K-Pg 事件中完全滅絕的傳統恐龍類群（排除現生鳥類）。 |
| **鳥類恐龍** | Avian Dinosaurs | 唯一在 K-Pg 滅絕事件中存活至今的獸腳類恐龍演化支（即現代鳥類）。 |
