# 恐龍分類學與骨盆結構 (Dinosaur Taxonomy and Pelvic Morphology)

> **導讀簡介**：1887 年，英國古生物學家哈利·西利（Harry Seeley）依據骨盆構造將恐龍總目一分為二：**蜥臀目 (Saurischia)** 與 **鳥臀目 (Ornithischia)**。這套經典分類法至今仍是恐龍學科的核心基礎。

---

## 1. 分類核心依據：骨盆三骨的幾何排列

恐龍骨盆由三對成對的扁平骨骼癒合組成：
1. **腸骨 (Ilium)**：位於背側上方，連接脊柱與薦椎，提供強大的腿部運動肌群附著點。
2. **坐骨 (Ischium)**：位於後下方，向後斜伸。
3. **恥骨 (Pubis)**：位於前下方，**其生長與指向方向是分類的決定性依據**。

```text
       【蜥臀目骨盆 (Saurischian)】                   【鳥臀目骨盆 (Ornithischian)】
               [ 腸骨 Ilium ]                               [ 腸骨 Ilium ]
                  /     \                                      /     \
    [恥骨 Pubis] /       \ [坐骨 Ischium]                     /       \ [坐骨 Ischium]
   (恥骨朝前傾斜)         (坐骨朝後)                (恥骨朝後平行) \ ===== // (恥骨後突平行)
                                                    [恥骨 Pubis]  \======//
```

---

## 2. 兩大核心支系架構

### 一、蜥臀目 (Saurischia, "Lizard-hipped")
* **骨骼特徵**：恥骨朝前方或腹面傾斜，坐骨朝向後方，整體結構類似原始爬行動物與蜥蜴。
* **主要支系**：
  1. **獸腳亞目 (Theropoda)**：幾乎全為雙足直立行走，多數為肉食性（如暴龍、異特龍、伶盜龍）。**現代鳥類即由此分支直接演化而來**。
  2. **蜥腳形亞目 (Sauropodomorpha / 蜥腳下目 Sauropoda)**：草食性，演化出四足著地、柱狀巨腿、長頸與長尾（如梁龍、腕龍、阿根廷龍）。

> [!IMPORTANT]
> **演化史上的命名悖論**：
> 雖然鳥臀目的名字直譯為「鳥類骨盆」，但**真正的鳥類（Aves）並不是從鳥臀目演化而來的，而是演化自「蜥臀目」中的手盜龍類獸腳恐龍**！鳥類的恥骨朝後平行，是與鳥臀目各自獨立發生的「趨同演化（Convergent Evolution）」。

---

### 二、鳥臀目 (Ornithischia, "Bird-hipped")
* **骨骼特徵**：恥骨在演化過程中向後旋轉，與坐骨緊密平行向後延伸，下腹騰出更大的腹腔空間容納龐大的植物消化發酵系統。
* **食性特徵**：全部為**植食性**，並演化出前端無齒的角質喙嘴以及前齒骨 (Predentary bone)。
* **主要支系**：
  1. **覆盾甲龍類 / 裝甲類 (Thyreophora)**：
     * **劍龍亞目 (Stegosauria)**：背具雙排骨板，尾具防禦尖刺（尾刺 Thagomizer）。
     * **甲龍亞目 (Ankylosauria)**：全身體表覆蓋骨板骨刺，部分末端特化出骨質重錘（尾槌 Tail club）。
  2. **角足龍類 (Cerapoda)**：
     * **鳥腳下目 (Ornithopoda)**：具備發達齒電池的雙足/四足植食者（如鴨嘴龍、禽龍）。
     * **頭飾龍類 (Marginocephalia)**：包含具骨質頭盾與面角的**角龍亞目 (Ceratopsia)**，以及頭骨頂部極厚骨質隆起的**厚頭龍亞目 (Pachycephalosauria)**。

## 3. 系統分類樹簡表

```text
Dinosauria 恐龍總目
 ├── Saurischia 蜥臀目
 │    ├── Sauropodomorpha 蜥腳形亞目 (巨型植食：腕龍、梁龍)
 │    └── Theropoda 獸腳亞目 (肉食與鳥類：暴龍、異特龍、馳龍科、現代鳥類)
 └── Ornithischia 鳥臀目 (全植食)
      ├── Thyreophora 裝甲類
      │    ├── Stegosauria 劍龍亞目 (劍龍)
      │    └── Ankylosauria 甲龍亞目 (甲龍、包頭龍)
      └── Cerapoda 角足龍類
           ├── Ornithopoda 鳥腳亞目 (鴨嘴龍科、禽龍)
           └── Marginocephalia 頭飾龍類 (三角龍、厚頭龍)
```
